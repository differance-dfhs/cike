# Contributing

Thanks for helping improve 此刻.

## Before opening a pull request

```bash
npm ci
npm run audit:public
npm run typecheck
npm test
npm run build
```

Use synthetic fixtures in tests, screenshots and bug reports. Never commit real messages, meeting notes, browser activity, project documents, access tokens or personal absolute paths.

Keep the product contract intact: one high-value intervention at a time, completed or consumed suggestions leave the main surface, model-generated actions are not quantity-capped, and risky external actions require explicit approval.

## Design changes

Preserve the capsule silhouette in every state, expand downward from the camera area, support reduced motion, and test the compact, glance and expanded surfaces separately.
